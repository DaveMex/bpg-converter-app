# Plan de Lanzamiento v1.1.0 - BPG Converter

## Objetivo
Preparar y empaquetar la versión 1.1.0 de BPG Converter con soporte multiformato en Linux (.deb, .rpm, AppImage), build Universal para macOS (x64 + arm64), conversión inversa (BPG → PNG/JPG), selector de carpeta de salida, mitigación de avisos de instalación en Windows y macOS (sin cuenta de pago) y limpieza de dependencias.

---

## Tareas

- [x] **1. Limpieza de dependencias y optimización de bundle**
  - Eliminar `react` y `react-dom` de `package.json` (no se utilizan, el frontend es JS Vanilla).
  - → *Verificar*: `npm install` ejecuta limpiamente y se reducen dependencias en `package-lock.json`.

- [x] **2. Corrección de assets e icono de Windows**
  - Crear/enlazar `icon.ico` en `src/assets/` a partir de `icon.png` / `favicon.ico` para resolver la referencia en `src/main.js` (línea 23).
  - → *Verificar*: La ventana de la aplicación carga el icono sin errores en consola.

- [x] **3. Expansión de formatos Linux y macOS Universal en configuración de build**
  - En `package.json`:
    - Configurar Linux para targets: `["AppImage", "deb", "rpm"]`.
    - Configurar macOS para target universal: `arch: ["universal", "x64", "arm64"]` y script `"dist:mac": "electron-builder --mac --universal"`.
  - Actualizar el workflow `.github/workflows/build.yml` (incluir herramienta `rpm` para Linux y soporte universal en Mac).
  - → *Verificar*: Los scripts de compilación de `package.json` y el CI reflejan los nuevos targets.

- [x] **4. Implementación de Conversión Inversa (BPG → PNG / JPEG)**
  - Habilitar selección y drag & drop de archivos `.bpg` en la interfaz.
  - Implementar decodificación vía `bpgdec.js` en el renderer hacia un canvas offscreen y exportar a buffer (PNG o JPEG con calidad seleccionable).
  - Crear handler IPC en `main.js` (`save-decoded-image`) para persistir la imagen resultante.
  - → *Verificar*: Al arrastrar o seleccionar un archivo `.bpg`, se convierte exitosamente a `.png` o `.jpg` y se previsualiza.

- [x] **5. Selector de carpeta de salida (Output Folder)**
  - Añadir en la barra lateral una opción para:
    - Guardar en la misma carpeta del archivo original (por defecto).
    - Elegir una carpeta de salida fija personalizada con botón "Examinar...".
  - Integrar la selección con IPC `select-directory` en `main.js`.
  - → *Verificar*: Al convertir hacia BPG o desde BPG, los archivos se depositan en el destino indicado.

- [x] **6. Guías de instalación sin cuenta de pago (Windows SmartScreen & macOS Gatekeeper)**
  - Documentar en `README.md` instrucciones claras para los usuarios:
    - **Windows**: Pasos para el diálogo SmartScreen (*"Más información"* → *"Ejecutar de todas formas"*).
    - **macOS**: Instrucciones para firma ad-hoc (Clic derecho sobre la app → *Abrir*, o `xattr -cr /Applications/BPG\ Converter.app`).
    - **Linux**: Instrucciones para instalar `.deb` (`sudo dpkg -i ...`), `.rpm` (`sudo rpm -i ...`) y dependencias de `AppImage` (`fuse2`).
  - → *Verificar*: La documentación está completa y formateada en GitHub Markdown.

- [x] **7. Actualización de versión y prueba de empaquetado**
  - Incrementar versión a `1.1.0` en `package.json`.
  - Probar build local de Windows con `npm run dist:win`.
  - → *Verificar*: El instalador `.exe` se compila sin errores en `dist/`.
